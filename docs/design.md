# Design Brief: Daily Tracker — "System Interface"

This is the implementation reference for the interface. Mechanics and data are defined in `PRD.md`; where sample data below disagrees with the PRD, the PRD wins. Render every label, title, button and message exactly as written, in sentence case. The only extra strings allowed are the ones defined in section 7. Notes about generating screens in Stitch live in `stitch-notes.md`.

Reference character used in all samples (illustrative, not a test fixture): Rank E, Level 3, 65 XP, Wallet 65, Streak 5, title Konsisten 7 hari, stats Str 16, Vit 12, Int 20, Disc 10, Soc 7.

Known simplifications in the samples: Today shows one row per stat, while the app shows all of a stat's anchors plus that day's rotating pick. Wallet equals Lifetime XP even though Rewards shows purchases. The History sample does not apply the 2x requirement on 23 and 25 Sep. See `decisions.md`.

## 1. Concept

Daily Tracker is a personal web app that turns daily habits into quests: completing tasks earns points, raises stats and rank, and missing tasks has consequences. Concept: a dark status window, like the system overlay in a story about someone quietly becoming stronger. Restrained at first, more striking as rank rises. It is not a fantasy pixel-art game and not a hacker terminal. All text in the interface is plain, direct language. Do not add extra labels, status strings, version numbers, IDs, sync indicators, capacity counters, decorative codes or footer text. There is no footer on any page.

Rules for the tokens:

- Page and panel background is `--bg`. `--surface` is for hairline borders, dividers and empty bar tracks. Text sits on `--bg`, not on `--surface`.
- Buttons always use `--action` with `--action-text`, at every rank, so they never look disabled. Completion check icons and signal-blue numbers or text use `--action-ink`.
- The current rank sets `--accent`. It is used only for the corner brackets, the rank chip, the rank letter, the level number, the XP bar fill and the radar chart. Rank E is soft steel blue, D signal blue, C steady teal, B deep violet, A amber gold, S radiant gold (a deep gold in light mode). The interface grows more striking as rank rises: the glow gets stronger (`--glow-px`).
- Glow is allowed only on the four corner brackets, the rank letter, the rank chip, the level number, and the one-time level up or rank up moment. Everything else is flat with a plain one pixel border, no drop shadows and no gradients.
- `--danger` is used only for penalty and warning states, the Berat tier marker, and the delete confirmation.
- Effort tier colors: Ringan `--tier-ringan`, Sedang `--tier-sedang`, Berat `--tier-berat`.
- `--icon-muted` is never used for text.

Measured contrast (WCAG): dark theme, text 15.5:1, muted text 7.2:1, `--icon-muted` 3.5:1, `--danger` 5.3:1 (all on `--bg`), button text on `--action` 7.3:1, rank accents 5.4:1 or more. Light theme, text 16.6:1, muted text 6.6:1, `--icon-muted` 4.3:1, `--danger` 5.4:1, `--action-ink` 5.4:1, rank accents 5.1:1 or more (all on `--bg`).

## 3. Typography

Manrope for all text, including navigation, buttons, section headers and labels, always in sentence case, never uppercase and never letter spaced. JetBrains Mono only for numeric values such as points, levels, XP, stat values, streak counts and dates. Both are self-hosted through `@fontsource-variable/manrope` and `@fontsource-variable/jetbrains-mono` (no external font CDN).

Default sizes: body 14/20, labels and helper text 12/16 in `--text-muted`, section headers 12/16 in `--text-muted` semibold, page titles 20/28 semibold, large readouts (rank letter, level number) 48/1 mono semibold, chips 12/16, form inputs 16 on small screens.

## 4. Layout and components

- Layout is left aligned with flat panels, thin one pixel hairline borders (`--surface`), minimal border radius (2px), and lists made of flat rows separated by hairline dividers rather than nested cards. All rows in a list have the same visual weight; no rows are dimmed.
- Progress bars are thin, two to three pixels, on a `--surface` track.
- **Corner bracket frame** (the signature device): a clearly visible L-shaped bracket, about 24 pixels per side and 2 pixels thick, at each corner of a screen's main panel, in `--accent`, with glow. Never repeated on inner elements. One reusable component, also used by the editor panels and the overlays in section 6.
- Icons are simple outline icons only (16px, 1.5px stroke): no emoji, no filled icons, no illustration. The single exception is the coin.
- **Coin icon.** A flat golden coin, about 16 pixels, round, `--coin` with a slightly darker `--coin-rim` rim and a small highlight. It is the only colored, non-outline icon. Show it directly before the balance in the Wallet chip and directly before every reward cost, including locked rewards. Earned task points and XP stay plain numbers without a coin, so the spendable Wallet is always visually distinct from XP.
- **Top bar** (every page, same everywhere). On the left the wordmark Daily Tracker, followed by five navigation items: Today, Tasks, Rewards, History, Settings, with the current page underlined in `--action-ink`. On the right three small chips: Rank E, Streak 5, Wallet 65. The rank chip is in the rank accent with glow; the other two are in `--text-muted` with monospace numbers; the Wallet chip shows the coin before its number. Chips are transparent with a one pixel `--surface` border. There is no avatar and no account control.
- **Buttons.** Primary: `--action` fill, `--action-text`, 2px radius, 36px tall (44px on small screens). A secondary action such as Cancel is plain text in `--text`.
- **Fields.** One pixel `--surface` border on `--bg`, a 12px label in `--text-muted` above, focus ring 2px `--accent`.
- **Toggles** (Anchor task, Theme): track `--surface`, thumb `--text`, on state `--action`.

## 5. Pages

### Page 1, Today

The screen uses the full desktop width, with two columns under the top bar. The content area has the rank accent corner bracket frame (soft steel blue for this rank E sample).

**Left column, the status window.** At the top, two readouts side by side: the label Rank above a large monospace E in the rank accent with its glow, and the label Level above a large monospace 3, right aligned. Directly under them, one line with the equipped title, styled subtly: Konsisten 7 hari (omitted when no title is equipped). Then the line 9 / 70 xp to Level 4, with a thin XP bar in the rank accent, about thirteen percent filled. Under the bar, one muted line: 1 freeze left this week. When a rank-up is blocked by the balance gate, one more muted line follows: Rank-up blocked: raise Soc to 45 xp (now 7). Below that, a five point radar chart with the axes Str, Vit, Int, Disc and Soc: a thin outline pentagon grid, with the user's values drawn as a shape filled in the rank accent at low opacity and a one pixel accent outline. The outer ring equals the largest stat value rounded up to the next multiple of 10, with a minimum of 20. Each vertex is labeled with the stat name and its monospace value: Str 16, Vit 12, Int 20, Disc 10, Soc 7.

**Right column, from top to bottom.** First, a system notification block with a thin border: a small title System message, and the text Complete at least 1 task in every stat today. Directly below it, for each penalized stat, a notification block with a `--danger` border and the text Penalty active: Soc needs 2 completions today.

Then the section Daily quest with the count 3/5 at the right (stats satisfied out of quest-active stats). Flat rows, each with a status icon, task name and points. Sample: Morning plank 90 seconds with a check icon and +3. Minum air 2L with a check icon and +3. Baca 10 halaman with an empty circle icon in `--icon-muted` and +3. Ibadah with a check icon and +3. Chat 1 temen with a warning triangle icon in `--danger` and the `--danger` text 0/2.

Row behavior. Tapping a row's status icon completes it. Points on a row are what completing it awards after the rank multiplier; a task with effort variants shows its lowest to highest award, for example +3 to +8, and expands inline into one option per tier on tap: tier color marker, tier name, short description, and the points it will award. Choosing a tier completes the row. A row that has reached its limit for the day shows the check icon and is not interactive.

After a divider, the section Rewards with up to two rows: the most expensive reward the Wallet can afford, and the most expensive one it cannot yet afford. Sample: Main game 2 jam with a coin icon and the number 60 in `--action-ink`, and a Buy button. Nonton bioskop with a lock icon, muted, and a coin icon before the text 65 / 800.

### Page 2, Tasks

Page title Task library, with the small muted text 11 tasks next to it (task families), and a signal blue button Add task at the top right.

Below, five sections with muted headers: Strength (Str), Vitality (Vit), Intellect (Int), Discipline (Disc), Social (Soc). Each task is a flat row with the task name, a small tag reading Anchor or Rotating, and on the right its points (nominal, before the multiplier), plus small edit and delete icons.

A task with effort variants is a family: a heading row with the family name and its Rotating or Anchor tag, then up to three indented sub rows, each showing a tier color marker, the tier name, a short description of what that tier requires, and its points on the right. A task with one difficulty is a single row with one points value, for example 5 pts.

Sample rows. Strength: Push up routine, Rotating, with Ringan, 10x2 set, 5 pts; Sedang, 20x3 set, 9 pts; Berat, 30x4 set or jogging 2km, 15 pts. Dead hang 60 seconds, Rotating, 8 pts. Morning plank 90 seconds, Anchor, 5 pts. Vitality: Minum air 2L, Anchor, 5 pts. Stretching 10 menit, Rotating, 4 pts. Intellect: Baca 10 halaman, Rotating, 5 pts. Belajar coding, Rotating, with Ringan, 30 menit, 6 pts; Sedang, 1 jam, 10 pts; Berat, 2 jam, 15 pts. Discipline: Ibadah, Anchor, 5 pts. On the right, an editor panel with the corner bracket frame, titled Add task (Edit task when editing). Fields: Task name, with the value Push up routine. A section titled Effort variants with the helper text Up to 3 tiers, containing three cards, each with a tier color marker, the tier name, a field labeled What to do and a field labeled Points. Ringan: 10x2 set, 5. Sedang: 20x3 set, 9. Berat: 30x4 set or jogging 2km, 15. A card with both fields empty is ignored; at least one card must be filled. ### Page 3, Rewards

Page title Rewards, with the small muted text 5 items next to it in the same sans-serif font, and a signal blue button Add reward at the top right. A flat list of rewards. Each row shows the reward name, its cost in monospace with a coin icon before it, and a small muted text such as Bought 4 times, since rewards are repeatable. If the Wallet covers the cost, the row has a Buy button. If not, the row shows a lock icon and the progress, for example 65 / 150. The lock and the progress are muted, but the reward name stays in a readable, only slightly dimmed color.

Sample rows, with a current Wallet of 65: Main game 2 jam, 60, Bought 4 times, Buy button. Kopi susu santai, 35, Bought 8 times, Buy button. Beli buku baru, 150, Bought 0 times, locked, 65 / 150. Jajan favorit, 250, Bought 1 time, locked, 65 / 250. Nonton bioskop, 800, Bought 2 times, locked, 65 / 800.

The Add reward panel uses the same corner bracket frame as the task editor, titled Add reward (Edit reward when editing). Fields: Reward name, and Cost with a coin icon before the number. Two buttons at the bottom: Save reward in signal blue and Cancel as plain text.

### Page 4, History

Page title History. Below it, a panel with the corner bracket frame containing the chart and the table. At the top of the panel, the label XP trend at the left and the current total 65 xp at the right, in monospace. Three small text buttons set the range for both the chart and the table: 7 days (the default), 30 days, All.

Then a thin line chart in the rank accent color on the dark background, with no fill, no gradient and no axis clutter, with x axis labels from 21 Sep to 27 Sep, and the line passing through these total XP values in order: 45, 20, 35, 34, 49, 56, 65, so it shows a sharp dip on 22 Sep and then recovers. Mark 22 Sep and 24 Sep with small `--danger` markers for days that lost points, and mark 26 Sep with a small upward marker in `--action-ink` for a level up. A rank up gets the same upward marker in the rank accent; a rank down gets a small downward marker in `--danger`.

Below the chart, a table with a header row in muted text: Date, Str, Vit, Int, Disc, Soc, Net points. One row per day, newest first, with the date in monospace muted text. A check mark means the stat was completed, a dash means it was missed, and a small empty circle means still pending. Net points are in `--action-ink` when positive and `--danger` when negative; net points are the change in Lifetime XP that day. A day saved by a freeze shows the muted text Freeze used after the date. The rows are: 27 Sep, checks for Str, Vit and Disc, empty circles for Int and Soc, +9. Then a highlighted single line with no points, reading Level up: 2 to 3, in the rank accent color with a brief glow. 26 Sep, checks for Str, Vit, Int and Disc, a dash for Soc, +7. 25 Sep, checks for all five, +15. 24 Sep, checks for Str, Int and Soc, dashes for Vit and Disc, -1. 23 Sep, checks for all five, +15. 22 Sep, dashes for all five, -25. 21 Sep, checks for Str, Vit, Int and Disc, a dash for Soc, +7. Highlighted lines never show points. Other highlighted lines read Rank up: E to D (rank accent, brief glow) and Rank down: D to E (`--danger`, no glow). For the All range, the table loads 60 days at a time with a plain text button Show more.

### Page 5, Settings

Page title Settings. A short list of flat rows with hairline dividers.

- Row Theme, with a light and dark toggle.
- Row Title, expandable into a list: No title first, then every title as a radio row. Unlocked titles can be selected; locked titles are muted and show their unlock condition. The equipped title is selected.
- Row Rank reference, expandable into a small read only table of the six ranks E to S with their level range, freezes per week, max points per task, point multiplier and penalty per missed stat.
- Row Data, with two buttons: Export data and Import data.

## 6. Level up, rank up, rank down

The one place glow and motion are spent. Transient overlays reuse the corner bracket frame and the rank accent colors.

- **Level up.** A centered panel with the corner bracket frame over a backdrop of `--bg` at 80% opacity. The label Level up, the new level as a large monospace number with glow, the line Level 2 to 3, and a Continue button (focused; Escape also closes). Motion: the backdrop fades in over 200 ms, the panel scales from 0.96 to 1 over 400 ms, and the glow pulses once. Total under 800 ms.
- **Rank up.** Same frame. The label Rank up, the new rank letter as a large monospace character with the strongest glow of that rank, the line Rank D, then four monospace rows for the new rank: Freezes per week, Max points per task, Multiplier, Penalty per missed stat. A Continue button.
- **Rank down.** No overlay and no motion. A quiet notice block at the top of Today with a `--danger` border and the text Rank dropped to D, with a plain text button Dismiss.
- Showing an overlay or dismissing the notice marks its `milestoneEvents` entry as seen. With several unseen events, show one at a time, oldest first.
- With `prefers-reduced-motion`, there is no scale and no pulse: overlays appear with an opacity change only, and the glow is static.

## 8. Responsive

- **1024 px and wider.** As described in section 5: two columns on Today and Tasks.
- **640 to 1023 px.** One column. On Today the status window comes first, then the quest. On Tasks the editor opens below the list. The top bar uses two rows: wordmark and chips, then the navigation.
- **Below 640 px.** The top bar has two rows: the wordmark with compact chips (coin kept), then the five navigation items evenly spaced, each at least 44 px tall. The radar chart scales to the container width (minimum 240 px). The History table scrolls horizontally inside its panel. Editors open as full-width panels. Corner brackets shrink to 16 px per side. Buttons are at least 44 px tall.

## 9. Accessibility

- Text contrast is at least 4.5:1 and non-text contrast at least 3:1 in both themes when the tokens above are used. Do not put `--danger` text on `--surface` in the dark theme.
- Status never relies on color alone: check, dash and circle icons, the 0/2 counter text, and the Over cap text all carry the meaning.
- Everything is reachable by keyboard; focus is always visible (2px `--accent` ring).
- The radar chart has `role="img"` and an `aria-label` that lists the five values. The History chart has the same, and the table is its text alternative.
- Respect `prefers-reduced-motion` (section 6).
